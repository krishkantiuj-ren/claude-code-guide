## 为什么需要这个技能？

**新手视角**：你刚安装了 Claude Code，打开对话框却不知道从何下手。这个技能会在每次对话开始时自动出现，像一个贴心的向导，引导你完成任何任务。

**老手视角**：你已经熟悉 Claude Code，但想要更高效的工作流程。这个技能可以帮你自动拆解复杂任务、生成详细流程、检测不耐烦情绪并切换模式。

## 向导的气质

这个向导的气质如同一个**引导型恋人**：

- **温柔耐心**：不管你问多少问题，都不会不耐烦
- **细心体贴**：主动察觉你的需求，但不过度打扰
- **鼓励支持**：当你遇到困难时，给予鼓励而非批评
- **懂得放手**：当你想要独立时，安静退到一边
- **随时都在**：你需要时，第一时间出现
- **不评判**：不管问多基础的问题，都不会嘲笑
- **会示弱**：承认自己也有不确定的时候
- **有分寸**：知道什么时候该问，什么时候该闭嘴
- **记住偏好**：你喜欢简洁回答，就不再啰嗦
- **会道歉**：识别错了会说"抱歉，我理解错了"

## 功能特点

- **自动问候**：每次对话开始时自动询问你是否需要帮助
- **多模式选择**：
  - 需要引导 → 详细模式/快速模式
  - 不需要 → 保持安静，随时可召唤
  - 保驾护航 → 平时安静，检测到任务时自动出现
  - 永久关闭 → 不再自动出现
- **智能任务检测**：自动识别你的任务需求并生成详细流程
- **不耐烦检测**：当你表现出不耐烦时自动切换到快速模式
- **关怀提醒**：详细模式下问了多个问题后，会主动询问是否切换快速模式
- **随时召唤**：输入 `/claude-guide` 可随时召唤向导

## 安装方法

### 方法一：直接复制文件（推荐）

1. 下载本仓库
2. 复制 `skills/guide.md` 到你的 Claude Code 技能目录，并重命名为 `claude-guide.md`：
   ```bash
   # Windows
   copy skills\guide.md %USERPROFILE%\.claude\skills\claude-guide.md
   
   # macOS/Linux
   cp skills/guide.md ~/.claude/skills/claude-guide.md
   ```
3. 重启 Claude Code 或开启新对话

### 方法二：克隆仓库

```bash
git clone https://github.com/krishkantiuj-ren/claude-code-guide.git
cd claude-code-guide
cp skills/guide.md ~/.claude/skills/claude-guide.md
```

## 使用方法

### 首次使用

1. 开启新的 Claude Code 对话
2. 向导会自动问候并询问你需要什么帮助
3. 使用方向键选择模式后回车确认

### 模式说明

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 需要引导 | 进入待命状态，你提到任务时自动帮你拆解步骤 | 复杂任务、学习新技能 |
| 不需要 | 本次对话保持安静，随时输入 `/claude-guide` 可重新召唤 | 简单任务、不想被打扰 |
| 保驾护航 | 平时安静，检测到任务关键词时自动出现 | 不确定是否需要帮助 |
| 永久关闭 | 今后所有对话都不再自动出现 | 不喜欢这个功能 |

### 引导模式

选择"需要引导"后，还可以选择：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 详细模式 | 逐步拆解，每步确认 | 复杂任务、需要学习 |
| 快速模式 | 跳过可选步骤，直接执行 | 简单任务、赶时间 |

### 随时召唤

在对话过程中，随时输入 `/claude-guide` 可以重新召唤向导。

## 工作原理

这个技能通过 Claude Code 的技能系统工作：

1. 技能文件 `claude-guide.md` 包含详细的向导行为规则
2. Claude Code 每次对话都会自动加载技能文件
3. 向导会根据你的选择和任务需求，自动调整行为模式

## 自定义

你可以根据需要修改 `claude-guide.md` 文件来自定义向导的行为：

- 修改问候语
- 调整模式选项
- 添加新的任务类型
- 修改不耐烦检测规则
