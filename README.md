# Agent 向导系统

一个给 Claude Code、Codex 等编程 Agent 使用的中文向导规则。它会在对话开始时先确认你需不需要引导；需要时拆步骤，不需要时保持安静。

这个项目原本叫 Claude Code 向导。现在我也在用 Codex，所以把定位改成更通用的 Agent 向导系统。

## 它适合什么场景

- 刚开始用编程 Agent，不知道怎么把需求说清楚
- 想让 Agent 先拆解任务，再一步步做
- 希望简单任务少打扰，复杂任务再进入引导
- 想统一中文交互、中文选项和中文提示

它不是一个新的客户端，也不是自动化框架。它本质上是一份可复用的规则文件，用来规范 Agent 在任务开始前怎么提问、怎么拆解、什么时候少打扰。

## 主要行为

- **开场确认**：每次新对话先问你是否需要引导
- **需要引导**：进入待命状态，识别到任务后再拆步骤
- **保持安静**：你不需要时，它不会主动推流程
- **保驾护航**：平时不打扰，检测到任务需求时提醒
- **快速模式**：当你想直接做时，减少提问，直接执行核心任务
- **中文优先**：面向用户的问题、选项、说明尽量保持中文

## 安装

### Claude Code

复制 `skills/guide.md` 到 Claude Code 的技能目录，并重命名为 `agent-guide.md`：

```bash
# Windows
copy skills\guide.md %USERPROFILE%\.claude\skills\agent-guide.md

# macOS/Linux
cp skills/guide.md ~/.claude/skills/agent-guide.md
```

然后重启 Claude Code，或者开启一个新对话。

### Codex

Codex 更适合把这份规则放进项目级 `AGENTS.md`，或放进你常用的全局指令里。

可以直接参考 `examples/CLAUDE.md` 的写法，把其中的“新手向导”和“语言：强制中文”部分复制到自己的 Agent 指令文件中。不同客户端的工具名称可能不一样，实际使用时按客户端支持的提问/选择工具调整即可。

## 使用方式

开启新对话后，向导会先询问：

> 我是你的向导，需要我帮你规划步骤吗？

你可以选择：

| 模式 | 作用 | 适合场景 |
|------|------|----------|
| 需要引导 | 进入待命状态，后续任务会被拆成步骤 | 复杂任务、学习新东西 |
| 不需要 | 本次对话保持安静 | 简单任务、不想被打扰 |
| 保驾护航 | 平时安静，检测到任务时出现 | 不确定要不要引导 |
| 永久关闭 | 后续不再自动出现 | 不想使用这个规则 |

选择“需要引导”后，还可以选择详细模式或快速模式。

## 文件说明

## 自定义

- 模式选项
- 任务识别关键词
- 是否强制中文
- 提问频率和快速模式规则
